# Scale Archive LP制作ブリーフ

## 製品と読者

| 項目 | 内容 |
| --- | --- |
| 製品名 | Scale Archive（有料プラン名は Scale Archive Plus） |
| 運営 | Moa Lab. |
| 製品概要 | 爬虫類の給餌、脱皮、体重などを個体ごとに記録し、履歴やカレンダーで振り返れる飼育記録アプリ。 |
| 主な読者 | 前回の給餌日や体重をさっと確認したい飼育者。1匹の記録から始めたい人も、複数匹の履歴を分けて管理したい人も対象。 |
| 想定場面 | 「前に食べたのはいつ？」「以前から体重はどう変わった？」「この子の通院で何を伝えよう？」と思ったとき。 |
| 対象・公開状況 | iOS・Android向け。一般公開前。ストアへのCTAはOSごとの公開と実際のURLを確認して切り替える。 |

LPでは、まず「個体ごとに記録を残して見返せる」ことを伝える。日常の記録はログイン不要で始められ、個体数が増えたり機種変更に備えたりしたいときにPlusを選べる。

## 機能一覧

| 分類 | 掲載できる内容 |
| --- | --- |
| 個体プロフィール | 名前・種類のほか、モルフ、性別、誕生日、お迎え日、購入店、メモ、プロフィール写真を登録。誕生日は不明・年のみ・年月でも登録できる。 |
| 個体一覧・ホーム | 名前検索、種類フィルター、並び替え。ホームで飼育中の個体と最近の記録を確認できる。飼育中の一覧から外すときはアーカイブで履歴を保持できる。 |
| 6種類の記録 | 給餌、脱皮、排せつ、通院、身体測定、その他。通院とその他は、記録ごとに写真を最大3枚添付できる。身体測定は体重と任意の全長に対応。 |
| 振り返り | 個体別タイムライン、年・記録種類で絞り込める履歴、体重グラフ、月間カレンダー。 |

| データ保存 | 基本機能の記録・写真は端末内に保存。Plusでは記録データのクラウドバックアップと暗号化移行ファイルの書き出し・読み込みに対応。 |

## 無料とPlusの違い

| 機能 | 無料 | Scale Archive Plus |
| --- | --- | --- |
| 飼育中の個体数 | 3匹まで | 3匹の上限を解除 |
| 基本の飼育記録と振り返り | 6種類の記録、個体別履歴、体重グラフ、カレンダー | 同じ基本機能を利用可能 |
| テーマカラー | プレビュー | 8色から選んでアプリ全体に適用 |
| クラウドバックアップ | 有効なPlus契約中に作成済みのバックアップがあれば、同じアカウントで復元可能 | 手動・自動バックアップと復元。保存はアカウントごとに最新1件 |
| 暗号化移行ファイル | — | パスワード付きファイルの書き出し・読み込み |
| 日本向けの価格 | 無料 | 月額300円または年額3,000円。いずれも自動更新 |

年額の比較を載せる場合は「月額300円を12か月利用した場合より600円少ない」。金額・提供地域・購入可否は、掲載前に各ストアの購入画面で確認する。

## FAQの回答案

**ログインしなくても使えますか？**

個体登録や日々の飼育記録は、ログインせずに使えます。Plusの購入やクラウドバックアップには、GoogleまたはAppleでのログインが必要です。

**端末を買い替えても記録を引き継げますか？**

クラウドに保存した記録は、同じアカウントでログインすると復元できます。復元すると移行先の端末にある記録は置き換わります。写真ファイルはバックアップに含まれないため、新端末へ別途移した写真を選んで、該当する記録につなぎ直せます。

**Plusの期限が切れてもバックアップは使えますか？**

同じアカウントでログインすれば、保存済みの最新バックアップを復元できます。新規保存、上書き、自動バックアップを使うには、有効なPlus契約が必要です。

**自動バックアップはどのくらいの頻度ですか？**

最初のバックアップまたは復元が済んだ端末で、毎日・毎週・オフを選べます。Wi-Fi接続時だけにする設定もあります。実行時刻は端末の状態やOSによって変わります。

**アカウントを削除するとデータはどうなりますか？**

アプリのクラウドバックアップ画面から退会できます。端末にある個体・記録・写真はそのまま残ります。ストアで契約した定期購入は、ストア側で別途解約してください。詳しくは[退会案内](https://moa-lab.com/scale-archive/account-deletion)をご覧ください。

## 公開前に確認する項目

- **ストア**。各OSの一般公開日、ストアURL、対応OSバージョン、最新の価格を確認して掲載する。未公開のOSには配信中の表示を付けない。
- **バックアップの表現**。「写真もバックアップ」「複数端末で自動同期」などは避ける。最新1件のバックアップから復元し、復元先の記録は置き換わる。写真は別途移行する。
- **飼育支援の表現**。診断、給餌スケジュールの提案、リマインダーなどを機能としてうたわない。架空の利用者数やレビューも掲載しない。
- **ポリシー**。[プライバシーポリシー](https://moa-lab.com/scale-archive/privacy-policy)と[退会案内](https://moa-lab.com/scale-archive/account-deletion)は公開済み。[利用規約](https://moa-lab.com/terms-of-service)は現時点のアプリ内リンク先で、Webサイト用と明記されている。LPへアプリ専用規約として載せる前に掲載先を確認する。[特定商取引法に基づく表記](https://moa-lab.com/commercial-transactions)もScale Archiveの記載を確認する。
