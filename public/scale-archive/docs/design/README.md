# Scale Archive LP 素材と公開準備

## 採用方向

ユーザー選択は「3案目の白地の図鑑・アーカイブ」＋「1案目の黒とゴールドの体重グラフ」。組み合わせの参照は `selected-direction.png`。LPは `../../index.html`、独立した利用規約とプライバシーポリシーは同階層のHTMLに配置した。

## 素材

| 出力 | 元素材・用途 |
| --- | --- |
| `../../img/brand-mark.webp` | アプリリポジトリ `scale_archive/assets/images/app_icon.png`。既存SAマークを縮小・WebP化。 |
| `../../img/animal-detail.webp` | アプリリポジトリ `scale_archive/docs/scale_detail/screen.png`。構図参考の個体詳細画面。実機撮影済み画像としては扱わない。 |
| `../../img/ball-python.webp` | 組み合わせ参照から、個体写真のみをImage Genで個別生成。透過、1448 × 1086px。 |
| `../../img/weight-chart.webp` | 1案目を参照しImage Genで個別生成。1200 × 800px。開発中の画面イメージ・サンプルデータ。 |
| `../../img/calendar.webp` | 既存カレンダーと採用案を参照しImage Genで個別生成。800 × 960px。開発中の画面イメージ。 |

画像生成は組み込みImage Genを使用。CLI/APIキーは使用していない。配信用素材はすべてプロジェクト内に保存し、cwebpで圧縮した。追加の外部CDN・JavaScript・フォント依存はない。

## 生成プロンプトの仕様

- **組み合わせ参照**：3案目の白地、ゴールド罫線、SAロゴ、コピー、個体写真とアプリ画面の構成を保持し、下部の体重グラフだけを1案目の黒茶地・金線・淡色目盛り・最新値コールアウトへ差し替える。期間は実仕様の30日／90日／180日／1年／全期間。日本語、公開前、CTA「機能を見る」。
- **個体写真**：採用参照の金色ボールパイソンを横長4:3の独立写真素材へ。頭は左下、コイルは右奥。自然な解剖と鱗、写真品質、透過、文字・ロゴ・UIなし。右上にアプリ画像が重なる配置。
- **体重グラフ**：1案目の黒茶#1E1B14／ゴールドを保持。横長1200 × 800、見出し「体重の推移」、30日／90日／180日／1年／全期間、180日選択。5月〜11月のサンプル、最新1.25kgと前回差の表示。余分なUIなし。
- **カレンダー**：黒茶#1E1B14、明るい日付と見出し、金色の選択状態と記録目印。年月は2026年11月、日曜始まり、1日と22日は日曜、22日選択。ヘッダーと月間カレンダーのみで、記録一覧や下部ナビは含めない。

## 公開前に差し替える情報

1. 公開用ビルドから架空の飼育データで実機スクリーンショットを取得し、画面イメージを差し替える。
2. 各OSの公開状況・ストアURL・対応OS・購入価格を確認し、公開したOSの実リンクのみ追加する。
3. アプリ内の利用規約リンク先を `https://moa-lab.com/scale-archive/terms-of-service.html` へ変更する場合は、アプリ側の作業として別途反映する。

規約関連ページは共通 `css/style.css` と `css/app-policy.css` を利用。既存プライバシーポリシー・退会案内のarticle本文と制定日は変更していない。新規利用規約の制定日は文書作成日であり、アプリのリリース日ではない。

検証結果は `../../design-qa.md`、ブラウザの確認画像は `qa/` を参照。
