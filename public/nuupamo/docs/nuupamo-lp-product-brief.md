## 製品の位置づけと名称

NUUPAMO（ヌーパモ）は、家庭内で「あるもの」と「買うもの」を共有する在庫・買い物管理モバイルアプリです。アイテムをタップして2つの状態を行き来させる操作が中心です。個数を数える在庫管理より、買う必要があるかどうかを共有する使い方を想定しています。

| 項目 | 現行仕様 |
|---|---|
| ロゴ・アプリ内の製品名 | NUUPAMO |
| 読み方・ホーム画面の表示名 | ヌーパモ |
| 有料プラン名 | NUUPAMO Plus |
| 対象 | iOS / Androidのモバイルアプリ |
| リスト | 同時に利用する在庫・買い物リストは1つ。共有参加前のリストは退出時の復帰用に保持 |

根拠: [名称定義](../lib/core/constants/app_brand.dart)、[プラン上限](../lib/core/constants/plan_limits.dart)、[共有参加・退出](../lib/features/invites/data/invite_repository.dart)。旧名のStocky / Stocky HomeはLPの製品名に使いません。URL・アプリID・課金商品IDに残る`stocky`は内部識別子です。

## LPの目的と想定読者

LPの目的は、「家にあるものと、これから買うものを家族で共有できる」と理解してもらい、無料プランでの利用開始につなげることです。冒頭は中心操作と共有の使い方を示し、有料プランは登録件数やメンバーを増やしたい人への選択肢として紹介します。

| 優先度 | 想定読者 | 想定する困りごと | 伝える使い方 |
|---|---|---|---|
| 主対象 | 夫婦・パートナーなど、買い物を分担する家庭 | 家にあるか、相手が買う予定か、その都度確認している | 同じ在庫・買い物リストを開いて確認する |
| 主対象 | 食材や日用品の買い置きを把握したい人 | 買うものを思いついたときに記録しておきたい | 「あるもの」から「買うもの」へタップで移す |
| 利用場面 | 子ども用品やペット用品もまとめたい家庭 | 誰のための用品かを見分けたい | カテゴリと担当者を設定する |
| 利用場面 | まずはひとりで試したい人 | 使い方を確かめてから登録や共有を始めたい | 登録を後回しにして無料で試す |

## 訴求ポイントと伝える順番

| 順位 | 訴求 | 機能上の裏付け | 伝え方の例 |
|---|---|---|---|
| 1 | 家族で同じ情報を確認できる | 在庫と買い物の状態を同じ共有リストへ反映 | 「家にある？」「買っておく？」を、同じリストで確認。 |
| 2 | 買い物リストを繰り返し使える | カードのタップで「あるもの」と「買うもの」を相互移動 | なくなったら「買うもの」へ。買ったら「あるもの」へ。 |
| 3 | 買い物のお願いを添えられる | 30文字の共有メモと担当者設定 | 誰にお願いするか、どんなものがほしいかも一緒に。 |
| 4 | 無料で共有まで試せる | 無料でも50アイテム・合計3メンバー、共有あり | 家族での共有も無料プランから。 |
| 5 | 家庭で使うものをまとめられる | 食材・日用品・ベビー・医薬衛生・ペット・その他の6カテゴリ | 食材も、日用品も、ペット用品も。 |
| 6 | 家族やペットの用品を見分けられる | アプリを使わない人やペットも担当者として登録可能 | 子どもやペットの用品にも、名前とアバターを。 |
| 7 | 共有相手にもPlusの特典が届く | 契約者が参加する共有リスト全体の件数上限を解除 | ひとりがPlusに申し込むと、同じ共有リストで上限を解除。 |

買い忘れや二重買いへの対策として紹介できますが、「必ず防げる」「買い物代が何％減る」といった成果は保証しません。担当者設定は表示上の割り当てであり、相手への通知や依頼の承認機能ではありません。

### 利用場面の例

1. 家で洗剤がなくなったら、洗剤のカードをタップして「買うもの」へ移します。
2. 必要なら移動直後に「詰め替え用をお願い」とメモを添え、担当者を選びます。
3. 買い物をする家族が同じ共有リストを開き、買うものとメモを確認します。
4. 買ったら「あるもの」へ戻します。メモは消え、次に買うときも同じカードを使えます。

これは機能説明用の利用例です。自動検知、プッシュ通知、購入履歴の記録を示す演出にはしません。

## 紹介できる機能

| 機能 | 内容と条件 |
|---|---|
| タップで移動 | カード本体をタップして「あるもの」と「買うもの」を切り替える。個別移動は確認なし |
| 共有 | 招待リンクまたはQRコードから同じ在庫・買い物リストを複数端末で利用。変更を共有相手へ反映 |
| 買い物メモ | 買うものに1件・30文字までの共有メモ。改行も可能。新規作成時・あるものからの変更時・移動直後に入力 |
| 担当者 | アイテムごとに1人を選択。カード右端のアバターから変更でき、担当なしも選べる |
| その他のメンバー | アプリを使わない人やペットも担当者として登録できる。この登録だけでは共有アプリ利用者にならない |
| お気に入り | アイテム画像のタップで登録・解除。一覧の先頭に表示 |
| 並べ替え | 名前の昇順・降順・よく使う順。よく使う順は「買うもの」への移動回数で判定 |
| 名前検索・カテゴリ絞り込み | 「あるもの」で利用可能。買うものの検索欄はない |
| 6カテゴリ | 食材、日用品、ベビー用品、医薬・衛生用品、ペット用品、その他 |
| アイテムの追加・編集 | 名前・カテゴリ・プリセット画像・状態・担当者を設定。編集は長押しから開く |
| まとめて購入完了 | 「あるものへ一括移動」で買うものをまとめて移動。実行前に確認 |
| サンプルデータ | 30件。初回は追加せずに始めることもでき、設定から追加・削除できる |
| プロフィール | 名前・プリセットアバター39種類または「画像なし」・背景色25色。「画像なし」は名前の先頭2文字を表示 |

根拠: [一覧と操作](../lib/features/inventory/presentation/inventory_page.dart)、[アイテムの定義](../lib/features/inventory/domain/stock_item.dart)、[並べ替え・状態管理](../lib/features/inventory/presentation/inventory_controller.dart)、[アバターと背景色](../lib/features/members/domain/family_member.dart)、[サンプルJSON](../assets/stocky_sample_data_30_items.json)。

メモは買うものの一覧・編集シートでは読み取り専用です。吹き出しのタップもアイテムの移動になります。あるものへ戻すとメモを消去し、個別移動直後の「元に戻す」では、ほかの新しい移動がなければメモも復元します。削除と一括移動には取り消し操作がありません。端末ごとにメモ入力をオフにしても、共有メモの表示は続けます。

## 無料プランとNUUPAMO Plus

| 項目 | 無料プラン | NUUPAMO Plus |
|---|---|---|
| 料金 | 無料 | 新規申込みは月額200円の自動更新 |
| 在庫・買い物リスト | 1つ | 1つ |
| アイテム数 | 合計50件まで | 件数上限を解除 |
| メンバー数 | 本人を含め合計3人まで | 人数上限を解除 |
| リスト共有 | 利用可能 | 利用可能 |
| メモ・担当者・お気に入り・サンプル | 利用可能 | 利用可能 |
| Plusの適用範囲 | — | 契約者が参加している在庫・買い物リスト全体 |

アイテム数は「あるもの」と「買うもの」の合計で、サンプルも含みます。メンバー数はアプリ利用者とその他のメンバーの合計です。プロフィール未登録でも本人用に1枠を確保するため、無料で追加できるその他のメンバーは2人までです。

同じ共有リストの1人がPlusを契約すると、そのリスト全体で上限を解除します。共有相手にそれぞれ契約を求める仕組みではありません。参加前のアイテムを招待先へ自動で統合する機能はありません。

年額1,800円の商品は既存契約の継続・復元用に保持していますが、新規購入画面には表示しません。LPの料金表で年額を選択可能なプランとして案内しません。実購入時の価格はアプリ・ストアの購入画面で確認します。

購入・購入復元・プラン変更にはアカウント登録またはログインが必要です。解約後も有効期限まではPlusを利用できます。アプリやアカウントの削除はサブスクリプションの解約になりません。契約管理画面をアプリから開く導線はiOSにあり、AndroidはGoogle Play側で管理します。購入復元は課金権利の復元で、別アカウントの在庫データの復元・統合ではありません。

根拠: [無料上限](../lib/core/constants/plan_limits.dart)、[購入画面と月額商品の選択](../lib/features/plus/presentation/plus_page.dart)、[共有リストのPlus判定](../lib/features/plus/data/board_plus_provider.dart)、[課金設計](revenuecat_board_plus_design.md)。

## 利用開始と共有の条件

1. ひとりで使う場合は、アカウント登録とプロフィール登録を後回しにできます。通常の初回案内は、アカウント・プロフィール・サンプル選択・使い方の4段階です。
2. 共有の作成・参加には、各利用者本人のメールアドレス／パスワードとプロフィールを登録します。
3. 招待側は「招待リンクを送る」でOS標準共有画面を開くか、リンクをコピーできます。近くの相手にはQRコードも使えます。招待の有効期間は作成から7日です。
4. 未インストールの相手はアプリをインストールした後、同じ招待リンク・QRコードをもう一度開きます。インストールだけで招待先へ自動参加する仕組みではありません。
5. 招待IDを保持してアカウント・プロフィール設定後に参加確認へ戻ります。参加操作後に登録・ログインした場合は参加処理を継続します。
6. 同名のその他のメンバーがある場合は、担当設定を引き継いで参加できます。同じリスト内に表示名を重複させることはできません。
7. 共有参加前のリストは残り、設定から共有を退出すると戻れます。別の共有リストへ参加する場合は先に現在の共有から退出します。参加中と退出後で適用されるPlusの状態が変わります。

未登録のデータもサーバーへ保存しますが、機種変更・再インストール後に本人のデータへ戻るにはアカウント登録が必要です。現在のデータを保つ新規登録と、既存データへ切り替えるログインを分けています。別アカウントへのログインでデータを自動統合することはありません。

根拠: [初回案内](../lib/features/auth/presentation/auth_gate.dart)、[招待の作成](../lib/features/invites/presentation/invite_create_page.dart)、[招待の参加条件](../lib/features/invites/presentation/invite_join_page.dart)、[招待の有効期限](../lib/features/invites/data/invite_repository.dart)。

## LPに使うコピー案

以下は掲載文のたたき台です。ストア導線と料金の公開確認後に使用します。

### ファーストビュー

**見出し**

> 「あるもの」も「買うもの」も、家族で共有。

**説明文**

> 食材や日用品を、タップで「あるもの」と「買うもの」へ。NUUPAMOは、家族で同じ在庫・買い物リストを使えるアプリです。買い物メモや担当者も一緒に確認できます。

**短い補足**

> 無料プランでも共有できます。アイテム50件・本人を含む合計3メンバーまで。

**CTA**

「無料ではじめる」を主な呼びかけとし、配信を確認したOSのストアボタンを置きます。登録については「ひとりなら登録を後回しに。共有にはアカウントとプロフィールの登録が必要です。」と補足できます。未公開のストアへのボタンは出しません。

### 中心操作の説明

> なくなったら「買うもの」へ。買ったら「あるもの」へ。
>
> カードをタップして移すだけ。いつも買うものは同じカードを繰り返し使えます。

### 共有とメモの説明

> 買い物のお願いも、一緒に。
>
> 「買うもの」へ移したら、「詰め替え用をお願い」などのメモを添えられます。担当者を選んで、買い物の分担もリストに表示できます。

### Plusの説明

> 登録するものが増えたら、NUUPAMO Plus。
>
> 月額200円で、アイテムとメンバーの件数上限を解除。同じ共有リストにも特典が反映されます。

料金の近くに「自動更新のサブスクリプションです。購入時の価格はアプリ・ストアの購入画面をご確認ください。」を添えます。「家族それぞれに月額200円」と受け取られる表現は避けます。

## FAQ用の回答案

| 質問 | 回答案 |
|---|---|
| 無料で使えますか？ | はい。アイテム合計50件、本人を含むメンバー合計3人まで無料で使えます。リスト共有や買い物メモも利用できます。 |
| 登録しなくても使えますか？ | ひとりで使う場合は、アカウントとプロフィールの登録を後回しにできます。共有の作成・参加には、利用する方それぞれの登録が必要です。 |
| iPhoneとAndroidで共有できますか？ | はい。iOSとAndroidのアプリで同じ在庫・買い物リストを共有できます。それぞれの端末にアプリをインストールし、招待リンクやQRコードから参加します。 |
| メンバー3人には誰が含まれますか？ | 自分を含むアプリ利用者と、アプリを使わない人やペットなどの「その他のメンバー」の合計です。 |
| 家族にアプリを入れてもらわずに、担当者として登録できますか？ | はい。「その他のメンバー」として登録できます。ただし、その登録だけで相手がリストを閲覧したり、通知を受け取ったりすることはありません。 |
| 買い物メモはいつ入力できますか？ | 買うものへの移動直後、新規作成時、あるものから買うものに変更する編集時に入力できます。30文字までで、買うものの一覧や編集画面では読み取り専用です。 |
| 数量や賞味期限も管理できますか？ | 数量・残量・賞味期限の管理には対応していません。「あるもの」と「買うもの」の状態で管理します。 |
| 共有をやめると、自分のデータはどうなりますか？ | 設定から共有リストを退出すると、参加前の在庫・買い物リストへ戻れます。共有リストのアイテムを自分のリストへ自動で移す機能はありません。 |
| Plusは家族全員が申し込む必要がありますか？ | 同じ共有リストのひとりが契約すると、その共有リスト全体でアイテム・メンバーの上限が解除されます。 |
| 年額プランはありますか？ | 現在、新規申込みは月額プランのみです。既存の年額契約は継続・復元できます。 |
| 機種変更後も使えますか？ | 登録したアカウントでログインすると、そのアカウントのリストを利用できます。未登録で使っている場合は、機種変更前にアカウントを登録してください。 |
| アプリを削除するとPlusも解約されますか？ | アプリやアカウントの削除では解約されません。契約したストアのサブスクリプション管理から解約してください。 |

## 現行機能に含めないもの

数量・残量・賞味期限の管理、バーコード読み取り、商品DB連携、ユーザー画像アップロード、複数リストの切り替え、プッシュ通知、Web / PWA版、外部EC購入リンク、広告、テーマカラー変更、買い切りプランは提供していません。これらをLPの機能として掲載しません。

広告SDK・外部アナリティクスSDKはありませんが、UID、操作・画面コード、時刻、OS、アプリ版などの自前計測はあります。「計測なし」「個人情報を収集しない」と説明しません。メールアドレスやプロフィールはアカウント・共有に使用し、アイテム名・プロフィール名・メモ本文は計測イベントに含めません。

根拠: [対象外の仕様](stocky_requirements_v7_flutter_firebase_plus.md)、[依存関係](../pubspec.yaml)、[自前計測のクライアント](../lib/core/analytics/product_analytics.dart)、[計測データの検証](../functions/src/product_analytics.ts)。

| データ収集なし・完全匿名 | ひとりでの未登録利用は可能。共有・課金・利用状況計測のデータは扱う |
| オフラインでもすべての操作が可能 | オフラインでの全面利用を保証しない。共有・保存は通信を使う |
| 業界初・他社より簡単・利用者満足度No.1 | 比較調査・実績の根拠がないため掲載しない |

### 画面素材の制作指示

| 素材 | 見せる内容 | 注意点 |
|---|---|---|
| メイン画像 | 「買うもの」と「あるもの」、担当者アバターが読める画面 | 実装にないボタン・数量・期限表示を足さない |
| 操作説明 | 洗剤など同じカードが2つの状態を移動する図 | 赤は買うもの、緑はあるもの。自動移動に見せない |
| 共有の場面 | 2台の端末で同じアイテムの状態を確認する場面 | 通信時間や即時性を数字で保証しない |
| 買い物メモ | 「詰め替え用をお願い」など短い吹き出し | 30文字以内。チャットや履歴一覧に見せない |
| メンバー | 利用者と、子ども・ペットなどのその他のメンバー | ペット自身がアプリを操作するような説明にしない |
| 料金 | 無料とPlusの比較 | 年額を新規購入の選択肢として出さない |

文章は暮らしの具体的な行動を中心にし、「タップ」「家族で共有」「買い物のお願い」などの言葉を使います。バックエンド名や課金SDK名は利用者向け本文には不要です。状態は色に加えて「あるもの」「買うもの」の文字でも区別します。
