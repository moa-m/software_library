# Mojilta 日本語・英語LP

`index.html` が `/mojilta/` の日本語LP、`en.html` が `/mojilta/en.html` の英語LPです。ヘッダーのFAQ右側から切り替えられ、移動中のセクションも引き継ぎます。ビルド不要のHTML・CSS・JavaScriptで実装しています。LP本体は外部フォント・ライブラリ・アクセス解析を読み込みません。アプリ専用ポリシー・規約ページは他アプリと同じ共通スタイルを使います。

2026-11-04にアプリの開発プロジェクトから移動した制作ブリーフ・画像・サンプル文書。

- [LP制作ブリーフ](LP_BRIEF.md)：仕様・訴求・ユースケース・掲載文案・全画像の使用用途。
- [画像ギャラリー](screenshots/index.html)：Android / iOS各23枚、計46枚の原寸PNG。
- [撮影条件・画像一覧](screenshots/README.md)
- [サンプル文書と利用説明](screenshots/samples/README.md)
- [仕様・字体ライセンスの参照資料](reference/README.md)

`branding/` には使用する提供アイコンの原本・不透明マスター・ホーム用モノクロ素材を同梱。アプリで使用する原本は移動元にも保持する。

制作ブリーフ・提供アイコン・原寸PNG・ギャラリー・参照資料・サンプル文書は保持しています。ストア操作・デプロイ・コミット・pushは行っていません。

## ローカルでの確認

1. `public/`（このディレクトリの1階層上）で `python3 -m http.server 8000 --bind 127.0.0.1` を実行。
2. ブラウザで `http://127.0.0.1:8000/mojilta/` を開く。
3. 英語版は `http://127.0.0.1:8000/mojilta/en.html`。
4. 画像ギャラリーは `http://127.0.0.1:8000/mojilta/screenshots/`。

## 料金・購入方針（2026-11-08反映）

Mojiltaプロジェクトの「買い切り価格を検討する」チャットと、アプリ側の `docs/14_PURCHASE_SETUP.md`、製品要件、アプリ内の規約・プライバシー説明を確認しました。

## 実装ファイルと画像

- `index.html`：日本語本文、実画面、料金・無料範囲・購入復元の案内、FAQ、Mojilta専用のポリシー・規約リンク。
- `privacy-policy.html` / `terms-of-service.html`：Mojilta専用文書。端末内のファイル参照・履歴・設定、コピー、外部サービス、履歴削除の範囲などを現行仕様に合わせて記載。運営者と問い合わせ先は既存の共通表記（Moa Lab / info@moa-lab.com）を使用。
- `en.html`：本文・FAQ・操作ラベル・メタ情報を英訳。英語UIと英語サンプル本文の実画面8枚を使用し、英語のポリシー・規約・商取引表記へリンク。
- `style.css`：製品のダーク配色、レスポンシブ配置、フォーカス、動きを減らす設定、remによる文字サイズ。
- `script.js`：639px以下で文字サイズ・Markdownの画像を切り替える処理。640px以上では2枚を併記。JavaScriptなしでも全画像とFAQを読める構成。
- `images/`：提供素材から生成した掲載用画像17枚。スクリーンショットは360px・720px幅のJPEG（品質93）、アイコンは192pxのPNG。原寸画像の本文・UI・時計の差し替え、切り抜き、合成はしていません。

掲載画面はAndroid・iOSを4枚ずつ使用。冒頭・表示設定・Markdownの比較はAndroid、文字サイズの比較・範囲選択・履歴はiOSです。比較の2枚は同じOSで揃え、各画像にOSを明示しています。

- 日本語と英語は静的HTMLとして個別に配信します。言語の自動判定や保存はせず、ヘッダーで選択できます。JavaScript無効時も言語リンクは使えます。
