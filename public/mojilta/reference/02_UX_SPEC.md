# UX仕様 — 画面・操作・状態

現行コードとの照合日: 2026-11-03。操作・設定値は実装に合わせて記載し、端末での検証状況は `10_IMPLEMENTATION_NOTES.md` に分ける。

## 画面遷移

`/` ホーム → `/reader/session` リーダー → 戻る → ホーム。ホーム → `/settings` 設定 → `/settings/preview` 表示プレビュー。ルート定義は `/reader/:id` で、文書はRiverpodの単一セッションに保持する。外部から開く場合は `/reader/incoming` へ移動し、戻り先がない場合はホームへ戻る。言語専用ルートはない。

### ホーム

- 上部：右上に設定の歯車アイコン、その右に言語専用アイコン（翻訳記号）を置く。言語アイコンの下にプルダウンメニューを開く。その下にMojiltaの大きな文字ロゴとキャッチコピー「文章はそのまま。読み方は自由に。」を36dp間隔で中央配置し、背面へ現在のアプリアイコンと同じMと本のモノクロロゴを薄く重ねる。横向きの低い画面では上部の余白を縮め、文字拡大時は折り返しとスクロールを許容する。
- ファイルを開く：初回でも可視、52dp以上の主要ボタン。
- 前回の続きから：永続アクセス可として記録された最新の履歴がある場合に、ファイル名と進捗目安を表示。存在・権限はタップして読み直す際に確認する。
- 最近開いたファイル：最新順。TXT/MD識別、ファイル名、直近時刻、行タップで再開。
- 最近一覧の削除操作は**履歴のみ削除**。元のファイルには一切触れない。
- 各行のメニューは「再選択」「履歴から削除」。一時アクセスの履歴には再選択の案内を表示し、行タップでもファイル選択を開く。永続アクセスの履歴でファイル消失・権限喪失が判明した場合は、リーダーのエラー画面から再選択する。
- 再選択は標準のファイル選択を開く操作で、旧履歴を新しいURIへ統合しない。異なるURIなら別の履歴になる。iOSのネイティブ側では同じURLの文書に既存のUUIDを再利用する。
- 画面遷移を起こすボタンは48×48dp以上の操作領域。

### リーダー

- 閲覧中は本文を主役にした画面。初期表示では操作UIを表示し、本文タップで表示/非表示を切り替える。検索中・アクセシビリティのナビゲーション有効時は操作UIを表示する。選択中のタップでは切り替えない。
- トップ操作：戻る、ファイル名省略、検索、表示設定。Markdownには原文/整形表示の切替ボタンを置く。文字コード表示がオンならタイトル行の右端に文字コードを表示し、タップで再デコードするコードを選べる。3点メニューは置かない。ボトム：薄い進捗表示（可能な場合のみ）。
- 本文横幅最大680dp。左右余白は画面幅に応じた自動変更ではなく、設定の16/20/28dp（既定20dp）を適用する。本文上下余白は20/40dp。
- 2指ピンチでfontSizeを12〜32sp（連続でも段階でも、触感が自然な方）に変更。単純なレイヤー拡大は禁止。
- 通常1指ドラッグはスクロール。長押し開始は**本文の範囲選択**。選択後のドラッグは選択範囲調節。コピーは端末標準に近いコンテキストメニュー。
- TXTは **ひとつの選択コンテキストを文書全体で保持**する設計を優先。段落ごとに独立した選択しかできない実装は不可。
- Markdownは見出し・強調・リスト・コード・引用をレンダリング。ブロックをまたぐコピーがレンダラー側で不可なら「原文を表示」アクションを用意し、**編集不可のSelectableText**としてユーザーが選択コピーできるようにする。どちらのモードにも編集ボタンはない。
- 検索UI：検索欄＋一致件数＋前へ/次へ＋閉じる。大文字小文字を区別しない、重複しない部分一致で検索し、前後移動は先頭・末尾で循環する。一致をアクセントでハイライト。Markdownは検索中に原文へ切り替わり、閉じると原文／整形切替ボタンの現在値に従う。検索中に切り替えなければ元の表示モードへ戻る。検索開始前の位置へ戻す機能はない。
- 閲覧位置はファイル単位に保持し、約2秒間隔と画面離脱・アプリ非アクティブ時に保存する。TXT・原文はUTF-16文字オフセット、Markdown整形は進捗率で近似復元する。再オープンで最新の原本を読み直すが、本文変更の常時監視や周辺文章による位置の再検索はしない。
- ファイルの文字列、改行、空白を勝手にトリミングしない。本文の行末スペースは視覚的に目立たなくてもコピー時に保持が原則。

### 設定

- **Appearance**：ダーク/ライト/システムの順（既定はダーク）、テーマカラーはDandelion（既定）/Ink Blue/Evergreen/Terracotta/Iris/Dusty Roseの順で6色を選択（2列、色スウォッチ・ラベル・選択チェック）。
- **ファイル本文の表示**：本文サイズ（ピンチで調節した値が同期）、行間（狭1.45/標準1.65/広1.85）、余白（狭16/標準20/広28dp）、フォント（ゴシック＝Noto Sans JP / 明朝＝Noto Serif JP / 手書き風＝Klee One）。設定画面では「ゴシック」「明朝」「手書き風」（英語はSans / Serif / Handwritten）のみを表示し、フォント名は含めない。初期値はNoto Sans JP。同じフォントファイルをAndroid・iOSへ同梱し、収録外の文字は端末のフォールバックを使う。4項目はファイル本文に共通で適用し、今後開くファイルにも使う。メニューやボタンの表示設定と区別して説明する。
- ファイルを開いていなくても、組み込みサンプルで4項目の変化を確認できる。利用可能な高さが240dp以上ならサンプルを上部に固定し、高さは利用可能高の32%を140〜220dpに収める。下の項目をスクロールして調整する。文字サイズスライダーは12〜32spを0.5sp刻みで変更し、数値表示は整数に丸める。ドラッグ中もサンプルに反映し、設定の保存は指を離したときに行う。ピンチは連続値で調整する。
- サンプルの拡大ボタンから専用の表示プレビュー画面を開く。実際の閲覧画面と同じ本文描画を使い、表示設定や2指ピンチで調整できる。ファイルアクセスや閲覧履歴の追加は行わない。
- 高さが足りない横画面では固定サンプルを省き、専用プレビューへのボタンを設定一覧に表示する。
- **About**：アプリバージョン。専用のライセンス画面とプライバシー説明は表示せず、必要な第三者ライセンス文・著作権表示はAPK内へ文書として同梱する。
- テーマカラーを選択すると全画面に即時反映。外観モードとアクセントの設定値は独立。
- 外観セクションのテーマカラーの下に「閲覧位置を表示」、続けて「文字コードを表示」のトグルを置く。文字コード表示の初期値はオフで、変更を保存する。
- 「閲覧位置を表示」は、閲覧画面下部とホームの「前回の続きから」カードにある位置バーの両方へ適用する。オフにすると両方とも非表示。閲覧位置の保存・再開は表示設定に関係なく行う。
- 閲覧中の表示設定シートにも本文設定・外観・テーマカラー・位置表示・文字コード表示を置き、Aboutだけを省く。シートは画面高の85%。専用プレビュー内の設定シートでは組み込みサンプルを重ねて表示しない。
- 設定の大項目は22sp・太字600と区切り線、中項目は16sp・太字700の本文色。表示変更を即時反映し、保存に失敗した場合は通知と再試行を表示する。
- 起動時の自動再開や外部ファイルの履歴追加を切り替える設定はない。通常起動はホーム、読み込みに成功した文書は一時アクセスも含めて履歴へ記録する。

### 言語

- ホームの歯車アイコンの右にある専用アイコンから開く。通常の設定画面・閲覧中の表示設定シートには言語項目を置かない。
- プルダウンに「日本語 / English / システム」を縦に並べ、現在の選択をチェックで示す。日本語・英語の選択肢は切替後も母語表記を維持する。専用画面へは遷移しない。
- 初期値はシステムで、端末の優先言語に従う。対応する優先言語がない場合は英語。選択するとメニューを閉じ、アプリ全体へ即時反映し、再起動後も保持する。本文は翻訳しない。戻る操作・メニュー外タップでは選択を変えずにメニューだけ閉じる。

### ファイルエラー時

- 権限取り消し：「ファイルにアクセスできません。再度選択してください。」ボタンを表示。
- 移動/削除：「ファイルが見つかりません。」と示す。アプリが削除したと誤認させない。
- デコード失敗：文字化けを無言で表示し続けず「文字コードを選択」からUTF-8 / Shift_JIS（Windows-31J）を再試行。
- 非対応形式：サポートする拡張子を簡潔に案内。
- 8 MiB超過・読み込み失敗：理由を表示し、再選択・ホームへ戻る操作を提供する。対応形式は `.txt` / `.md` / `.markdown`。
- UTF-8の選択にはBOM付きUTF-16 LE/BEの判定も含む。タイトル行の表示はこの場合も「UTF-8」で、判定したUTF-16の種類を表示する機能はない。

## アクセシビリティ・多言語の配慮と検証範囲

- 画面文言はARBで `ja` / `en`。長い翻訳でもボタンとファイル名が壊れない。
- 画面の縦横回転、システム文字拡大、TalkBack、キーボード操作を考慮。
- 色のみで選択状態を伝えない（✓や枠線）。
- 日本語の全角字下げ、句読点、絵文字を欠損させない。右横書きRTLは将来拡張しやすいDirectional APIを使用。
- 小画面・文字拡大の自動テストと、TalkBack/VoiceOver等の実操作確認は区別する。各OS・端末での確認済み範囲は検証記録を参照する。

## 操作の状態優先順位

ボトムシート・プルダウン・キーボードは端末／Flutter標準の戻る操作で閉じる。リーダーの戻る処理では検索を優先して閉じ、次に選択解除、最後にリーダーを閉じる。2本目の指が触れたら未成立の長押しを取り消し、成立済みの選択も解除する。ピンチ後に片指が残っても選択・スクロールを再開せず、全指が離れたら通常操作に戻す。
