1. Scope

These terms govern your use of Mojilta (“the app”), which is provided by Moa Lab (“we”). Please review these terms before using the app.

The app is a reader for TXT and Markdown files that you provide. It leaves the original files unchanged. These terms apply to the app. For browsing the website, including the Mojilta product page, see the Website Terms of Service (Japanese).

2. Requirements for use

To use the app, you need a compatible device and operating system and read access to the files you want to open. Minors should obtain consent from their legal representative where necessary before using the app. The app’s Privacy Policy describes how we handle user information.

3. Reading, display, and copying

The app supports TXT (.txt) and Markdown (.md or .markdown) up to 8 MiB per file. It does not support PDF or EPUB. A file may fail to open or display differently depending on its contents or text encoding.

Changes to the font, text size, line spacing, and margins affect how text is displayed in the app. The app has no features for editing text, overwriting original files, or deleting or renaming them.

You can select and copy text across paragraphs in TXT files and in the read-only Markdown source view. To copy across blocks in a formatted Markdown document, switch to source view. The app does not display images in Markdown and does not reproduce all Markdown syntax or formatting exactly.

4. Managing files and resuming from history

The app does not store, back up, or sync original files. Please manage and back up files you need. Keep the originals and any necessary copies in case files are lost or deleted, your device fails, or similar problems occur.

When you resume from history, the app reads the original file again and opens it near your previous reading position. You need to select the file again if access was temporary, the file was moved or deleted, or permission to access it was lost. Changes to the original file or other factors may prevent the app from returning to the same place. The formatted Markdown view restores an approximate reading position.

Deleting history removes the history entries. It does not delete the original files, revoke access permissions managed by the operating system, or remove references used to reopen files on iOS.
