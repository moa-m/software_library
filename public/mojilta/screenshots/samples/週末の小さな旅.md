# 週末の小さな旅

遠くへ行かなくても、いつもと違う朝はつくれる。
川沿いを歩いて、小さな喫茶店でひと休みする週末のメモ。

## 朝の散歩

駅を出たら、**川沿いの遊歩道**へ。
目的地を急がず、気になった路地や店先で足を止める。

- 橋の上から、水面の光を眺める
- 焼きたてのパンをひとつ選ぶ
- ベンチで、今日読みたい文章を開く

> 予定を詰めすぎない。
> 寄り道できる時間も、旅の一部。

## 鞄に入れておくもの

- 小さなノートとペン
- 飲み水と折りたたみ傘
- 読みかけのTXTと、散歩のメモ

**ひとつだけ決めること：昼ごはんの前に、手紙を書く。**

## 午後の過ごし方

| 時間 | したいこと |
| --- | --- |
| 10:00 | 川沿いをゆっくり歩く |
| 11:00 | 窓際の席でお茶を飲む |
| 12:00 | 気になったお店で昼ごはん |
| 14:00 | 今日の景色を短く書き留める |

## 帰ってからのメモ

朝に見た景色を三つだけ残す。
立派な旅行記にしようとせず、その日の自分が覚えていたいことを書く。

```text
水たまりに映った青空
橋ですれ違った人の会釈
窓辺に置かれた白いカップ
```

また出かけたくなったら、このメモの続きを書こう。
