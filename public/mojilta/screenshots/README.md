撮影期間: 2026-11-03〜04（日本時間）。現在のアプリを実際に操作し、同じオリジナルTXT / Markdownを使って撮影した素材です。物理端末ではなく、Androidエミュレータ・iOSシミュレータで撮影しています。

| OS | 枚数 | 原寸 | 撮影環境・実ビルド |

| Android | 23 | 1080 × 2424 px | Pixel 9 AVD / Android 17（API 37）、1.0.0+2 |
| iOS | 23 | 1206 × 2622 px | iPhone 17シミュレータ / iOS 26.5、1.0.0+3 |

## LPで見せる場面

| 場面 | 内容 |
|---|---|
| ホーム | 実際に開いた2文書の履歴と、前回の続きからのカード。 |
| TXTを読む | 全角字下げ・空行のある短編を通常表示、操作UIを隠した表示、大きい文字で閲覧。 |
| 選択・検索 | 複数段落を選択、文中の「手紙」を検索して結果を表示。 |
| Markdown | 見出し・強調・箇条書き・引用の整形表示、表・コード、閲覧専用原文。 |
| 表示の調整 | 本文設定、拡大プレビュー、外観と6色、文字コード選択、言語プルダウン。 |
| 字体と外観 | ゴシック・明朝・手書き風、ダーク／ライトの実表示。 |

サンプル本文を表示するのはファイル閲覧画面です。設定内のサンプル・専用プレビューにはアプリ標準の文面が表示されます。エラー画面やストア管理画面は通常利用を見せる素材に含めていません。

本文は今回新規に作成したもので、既存の小説・記事・歌詞等からの引用や転載はありません。個人の原稿・実在人物の情報・実在店舗の写真等は使っていません。サンプル本文は本プロジェクトの紹介・LP・ストア素材等に再利用・改変でき、出典表記は不要です。

この利用説明はサンプル本文に対するものです。アプリアイコンは提供画像の造形を維持し、フォントなどにはそれぞれのライセンスが適用されます。[アイコン仕様](../reference/08_ICON_SPEC.md)と[同梱フォントの情報](../reference/FONTS.md)を参照してください。

## 制作時の注意

- PNGはOSのネイティブ出力です。本文・UI・時計の差し替え、画像合成、端末フレームの追加は行っていません。ギャラリーの縮小表示も同じ原寸ファイルを参照します。
- ステータスバーとファイル履歴の時刻は撮影端末の表示です。画像を並べる際は、各OS・外観・字体が分かる組み合わせを選んでください。
- 同じ画面でも字体・文字サイズ・左右余白などの設定が異なる素材があります。各OSの一覧で条件を確認してください。
- 複数段落コピーの訴求にはTXTまたはMarkdown原文の画像を使います。Markdown整形表示で連続したブロック横断選択ができるように見せないでください。
- この素材はアプリの実画面の紹介用です。全端末での動作保証やストア公開済みという意味ではありません。
